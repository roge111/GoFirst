# 🖊️ Синтаксис

Любая программа на Go начинается с объявления пакета: `package name_package`.

`import (name_l)` — позволяет импортировать необходимые библиотеки. Например:

```
import (
	"fmt"
	"bufio"
	"os"
)
```
### ⌨️ Считывание с клавиатуры
---

Чтобы считать с клавиатуры, мы используем библиотеки `bufio` и `os`.

- `bufio.NewScanner(os.Stdin)` — это позволит нам открывать вход для данных с клавиатуры и «сканировать» их.
- `.Text()` — достает текстовые данные из сообщения с клавиатуры.

Полный и правильный алгоритм считывания данных.

```
scanner := bufio.NewScanner(os.Stdin)

	_ = scanner.Scan()
	result:= scanner.Text()
```

На опыте я понял, что первую строку писать постоянно не требуется.


### Вывод на экран
---

Чтобы вывести на экран, то воспользуемся `fmt`:

- `Println` — вывод аргументов с переносом на следующую строку в конце.
- `Print` — вывод без переноса на следующую строку.

Пример:
```
fmt.Println(result)
```

### Функции
---
Как и в любом другом языке, мы можем создавать свои функции. Для этого используем ключевое слово `func` от слова "function". Далее следует название с перечислением принимаемых аргументов на вход в скобках. После скобок можно указать и тип возвращаемого значения. В примере - это строковый тип.
Скобки могут быть и пустыми. Это будет означать, что функция не принимает входных данных.

Пример:

```
func input()string{
	scanner := bufio.NewScanner(os.Stdin)

	_ = scanner.Scan()
	result:= scanner.Text()
	return result
}
```



### API
---
Одна из важных задач в разработке — работа с запросами. Для этого могут использоваться разные библиотеки. Например, `net/http`.

Функции `net/http`:
- `net.HandleFunc` — регистрирует обработчик для указанного пути. Ну, то есть мы указываем то, что данная программа обрабатывает запросы из указанного файла httml.
- `http.ListenAndServe` — запускает HTTP-сервер.
- `http.Error` — отправляет клиенту ошибку с указанным статусом.
- `http.ResponseWriter` — интерфейс для записи ответа клиенту.
- `http.Request` — структура для работы с входящим запросом.
